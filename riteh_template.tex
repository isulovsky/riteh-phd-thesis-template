\subsection{Literature Review}\label{Literature Review}
Literature review may well fit in the introduction. In this template, authoryear formatting has been set for citations. For example: "This has been shown in \cite{patankar1980numerical}".\\

Also, when referencing, pay attention to inline citations:\\ 

With inline citations you want to use citep, for example: \citep{patankar1980numerical} first established and verified pressure-velocity coupling for steady-state \ac{CFD}.\\

While for "regular" citing you want to use clean cite, for example: "This has firstly been shown in \cite{patankar1980numerical}".\\
